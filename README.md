# LAZAREV. Website Clone

A frontend clone of the LAZAREV. digital product design agency website, created as a practice project to improve my skills in **HTML, CSS, JavaScript, animations, and modern website interactions**.


## 📌 About The Project

This project recreates the visual style and interactive experience of the LAZAREV. website.

The main focus of this project was not just recreating the layout, but also implementing interactive animations and smooth scrolling effects using JavaScript animation libraries.

The website includes:

* Animated navigation menu
* Hero section with animated loading effect
* Interactive service/content sections
* Image hover effects
* Interactive showreel video
* Case study sections
* Expandable UI/UX and Product Design sections
* Digital Product Design Process section
* Smooth scrolling
* Scroll-triggered animations
* Responsive styling for smaller screens

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, layout, responsive design and hover effects
* **JavaScript** — Interactions and animations
* **GSAP** — Advanced animations
* **GSAP ScrollTrigger** — Scroll-based animations
* **Locomotive Scroll** — Smooth scrolling
* **Remix Icon** — Icons
* **Google Fonts** — Typography

The project loads GSAP, ScrollTrigger, Locomotive Scroll, Remix Icon and Google Fonts through external CDNs.

## ✨ Features

### Smooth Scrolling

Locomotive Scroll is used to create a smooth scrolling experience, with ScrollTrigger integrated for scroll-based animations.

### Animated Navigation

Hovering over the navigation reveals additional menu items using GSAP animations.

### Interactive Content Hover

The content cards in the insights section display images that follow the cursor when hovering over them.

### Interactive Showreel

The showreel section contains a video that expands and starts playing when the play button is clicked. Clicking the video pauses it and hides it again.

### Case Study Hover Effects

Case study sections use images and videos, with the video appearing and playing when the user hovers over the project area.

### Scroll Animations

The Digital Product Design Process section uses GSAP ScrollTrigger to animate its content as the user scrolls.

## 🎨 Design

The website uses a dark and minimal visual style with:

* Large typography
* High-contrast sections
* Green accent elements
* Rounded buttons
* Interactive hover states
* Large visual case studies
* Smooth transitions and animations

The primary page sections are implemented as separate sections/pages covering the hero, insights, showreel, success stories, case studies, services, and design process.

## 📱 Responsive Design

Basic responsive styling has been added using CSS media queries, particularly for the logo/brand section on smaller screens.
